# 0.8.0

中心仓直接依赖 `jinguissl = "0.8.0"`，导入 `jinguissl.contract.*`。
本版传递依赖中心仓 `jinguissl_core = "0.8.0"`，不需要相邻源码目录或Git锁。

- 提供国密算法/PKI/传输构件主桥，以及自有TLS/QUIC客户端和DTLS身份、认证会话、SRTP秘密快照。
- 修复TLS关闭待发送握手飞行及SSH reset异常映射，统一秘密所有权和异常边界。
- 根manifest、锁、25份示例传递锁和运行时版本一致；CI检查Git/中心仓锁漂移及直接Core导入。
- 应用媒体处理、信令信任、网络调度仍由消费方负责；不要仅替换import而保留绕过认证的本地实现。

0.7.7不包含全部新增入口。按正常语义版本升级并保留锁文件；不要静默回退到自建或拷贝的核心/主桥副本。范围及未验能力见能力矩阵，不以包发布代替应用验收。
